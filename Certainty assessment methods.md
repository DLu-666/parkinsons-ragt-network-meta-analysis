# Certainty assessment rules for the revised evidence set

Scope: all 47 primary network contrasts across seven outcomes. No new search, outcome extraction, effect-estimate model, or ROBUST domain reassessment. An SMD reference interval of -0.2 to +0.2 was used. This interval was selected during revision, is not a validated clinical MCID, and was not prospectively specified.

Framework: CINeMA, using Nikolakopoulou et al. (2020), doi:10.1371/journal.pmed.1003082 (existing manuscript reference 44), and the CINeMA manual downloaded from https://cinema.ispm.unibe.ch/model/CINeMA_manual.pdf. These are manual framework assessments assisted by deterministic code. They are not output from the official CINeMA web application and are not output from the local App's diagnostic-accuracy auto-calculator. The unchanged local App CSV preparation and heatmap functions were used to validate/display the final domain table.

1. Contributions: recompute the existing generalized least-squares electrical-flow approximation using each trial's primary covariance plus heterogeneity variance at the saved posterior-mean tau. Preserve the multi-arm covariance. Decompose flow into shortest source-to-sink paths, split each stream equally among its edges, and allocate edge contributions in proportion to trial conductance. This is a plug-in approximation to information contributions in the Bayesian NMA, not a posterior distribution of contributions. Validate sums, graph balance and reverse-contrast invariance. Do not reuse the withdrawn certainty grades.
2. Within-study bias: retain the outcome-specific ROBUST inputs. Use the published CINeMA Average rule: study scores low=1, moderate=2, high=3; contribution-weighted score rounded to nearest integer (ties towards greater concern). Result 1=no, 2=some, 3=major concerns. Existing sensitivity analyses support interpretation but do not automatically erase a high-risk contribution.
3. Reporting bias: suspected, with one applied downgrade, for the present published English-language evidence set. Unpublished and registry evidence has not been comprehensively reconciled; this can omit unfavourable results. No statistically demonstrated publication bias is claimed. Small-study tests were not run and their absence is not evidence of no bias. Search updating remains outstanding and may change this judgment.
4. Indirectness: record trial-level low or moderate relevance concerns based on source-described candidate effect modifiers; apply the same contribution-weighted Average rule. Picelli 2012a: more advanced H&Y 3-4; Carda 2012: H&Y below 3; Kim 2022: cue-assisted intervention and permitted continuing rehabilitation; Kawashima 2022: older cohort and a three-month, low-frequency programme; McGibbon 2024: multimodal exercise with or without an exoskeleton over eight weeks. These differ from the predominant four-week gait-practice regimens or severity distributions. Other pooled trials have low indirectness under the stated broad RAGT question. Small sample size alone and absence of a direct trial are not reasons for indirectness downgrading. Furnari is not pooled and receives no comparison weight. These judgments do not establish transitivity.
5. Imprecision: apply the CINeMA null/opposite-boundary rule to the 95% CrI. Intervals entirely within [-0.2,0.2] have no concerns. Otherwise, count crossings of zero and the reference boundary opposite the point estimate: zero/one/two crossings give no/some/major concerns. This evaluates standardized directional uncertainty, not clinically validated equivalence.
6. Heterogeneity: use existing posterior predictive intervals under the primary consistent random-effects model. Compare their boundary-crossing count with that of the CrI (CINeMA manual Table 4): zero/one/two additional crossings give no/some/major concerns. A wide CrI already allowing both directions is not downgraded twice merely because the prediction interval is also wide. Prediction intervals are uncertain in sparse networks and conditional on the fitted model.
7. Incoherence: use the three saved valid independent CET-TT splits (10MWT, 6MWT, balance). Posterior two-sided tail probability >=0.10 gives no detected concerns, without claiming proof of consistency. Networks without an independently testable loop receive major concerns under the CINeMA manual's no-loop rule. Comparisons without a valid local split in a network with a tested loop receive some concerns: available loop evidence is acknowledged, but no global design-by-treatment test or comparison-specific evidence is invented. This is an explicitly documented conservative manual judgment; untestable does not mean detected incoherence.
8. Overall: start High for randomized evidence. Some/major concerns correspond to one/two levels. Count within-study bias and reporting bias separately, but use only the larger penalty within each related pair (imprecision/heterogeneity and indirectness/incoherence). This implements CINeMA's joint-domain judgment to avoid duplicate penalties. Floor at Very low. Preserve both raw six-domain judgments and the four applied components in the audit CSV. Validate arithmetic using the unchanged local App generic rating function on these four applied components; do not pass treatment data to the DTA auto-calculator.
9. Status: the research team completed manual verification of the extracted data, ROBUST judgments and certainty ratings for the current revised evidence set. Certainty must be reassessed if the evidence set changes. The reference interval was not clinically validated or prospectively specified. The final database search date was 5 March 2026.
